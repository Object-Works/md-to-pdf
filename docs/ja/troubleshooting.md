# 困ったとき

[README](../README.md) > 困ったとき

## 図が描かれず、赤字のエラーとコードが出る

```
⚠ Mermaid 図1 を描画できませんでした: Mermaid 図や数式を描くためのブラウザを起動できませんでした: …
```

Mermaid の図と数式は、Puppeteer が起動するヘッドレス Chrome で描きます。ブラウザが入っていないときは、次のコマンドで入れてください。

```bash
npx puppeteer browsers install chrome-headless-shell
```

Docker や CI などでサンドボックスのエラーが出たときは、自動で `--no-sandbox` を付けて起動し直します。それでも起動しないときは、Chrome が必要とするライブラリ（`libnss3` など）が入っているか確認してください。図も数式も要らないなら `--no-mermaid` を付けると、ブラウザを起動しません。

## 図のエラーで `Parse error` と出る

Mermaid の書き方の誤りです。エラーの `line 3` などを手がかりに直してください。[Mermaid Live Editor](https://mermaid.live/) に貼り付けると、どこが誤りかを確かめやすくなります。ほかの部分は変換されています。

## 図が小さくて読めない

ページに収まらない図は縮小します。縮小率が 70% を下回ると、次の注意が出ます。

```
注意: 図6 をページ内に収めるため 42% に縮小しました。
```

- 横に長い図（ガントチャート、`flowchart LR` で項目が多い図）は `--landscape`
- 全体に大きい図は `--format A3`
- 図を分けられるなら、2つの図に分ける

## `〓` が出る

フォントにない文字です。ハングル、タイ文字、アラビア文字などは対応していません。どの文字が置き換わるかは [文字とフォント](fonts.md#描けない文字の置き換え) を見てください。

## 画像が `［画像: …］` になる

- パスが Markdown ファイルからの相対パスになっているか確認してください（ライブラリで文字列を渡すときは `basedir`）
- `http(s)://` の画像は読み込みません。手元に保存して相対パスで指定してください
- SVG や GIF は使えません。PNG か JPEG にしてください

## 改ページの位置が思ったところと違う

- `#` の前で必ず改ページしたくないときは `--page-break none`
- `##` ごとに新しいページから始めたいときは `--page-break "# ##"`
- 見出しの直後の内容が長いと、見出しごと次のページへ送ることがあります。規則は [組版と改ページ](layout.md) を見てください

## リストの番号が続いてしまう

空行だけでは前のリストが終わらないためです（CommonMark の決まり）。2つのリストの間に `<!-- -->` をはさんでください。

## `--css` が効かない

ブラウザで組版しないため、CSS は反映しません。用紙・余白・改ページはオプションで指定してください。

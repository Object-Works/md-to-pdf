# コマンドライン

[README](../README.md) > コマンドライン

```bash
md-to-pdf <file.md> [file2.md ...] [options]
```

## オプション

| オプション | 説明 | 既定 |
| --- | --- | --- |
| `-o, --output <path>` | 出力 PDF のパス。複数ファイルのときは出力ディレクトリ | 入力と同じ場所・同じ名前の `.pdf` |
| `-f, --format <size>` | 用紙の大きさ。`A3` `A4` `A5` `Letter` `Legal`（大文字・小文字は区別しません） | `A4` |
| `--landscape` | 横向きにする | 縦向き |
| `--margin <size>` | 余白。[余白の書き方](#余白の書き方) を参照 | `16mm 16mm 18mm 16mm` |
| `--page-break <levels>` | 必ず改ページする見出しのレベル。[改ページ](layout.md#改ページ--page-break) を参照 | `"#"` |
| `--no-mermaid` | Mermaid の図と数式を描かない。図はコードブロック、数式は `$…$` の文字のまま出し、ブラウザも起動しません | 描く |
| `--no-page-numbers` | 右下のページ番号（`3 / 12`）を付けない | 付ける |
| `--css <file>` | 受け付けますが反映しません（ブラウザで組版しないため） | |
| `-h, --help` | ヘルプを表示 | |
| `-v, --version` | バージョンを表示 | |

## 出力先

- `-o` を省略すると、入力ファイルと同じディレクトリに、拡張子を `.pdf` にした名前で書き出します（`doc.md` → `doc.pdf`、`.markdown` も同じ）
- `-o` に既存のディレクトリか `/` で終わるパスを渡すと、その中に同じ名前で書き出します
- 複数ファイルを変換するときは、`-o` にディレクトリを指定してください（省略した場合はそれぞれ入力と同じ場所）
- 出力先のディレクトリがなければ作ります
- 書き出した PDF のパスを標準出力に、進み具合（`変換中: …`）と注意を標準エラー出力に出します

```bash
md-to-pdf README.md                      # ./README.pdf
md-to-pdf docs/a.md -o out.pdf           # ./out.pdf
md-to-pdf docs/*.md -o dist/             # dist/a.pdf, dist/b.pdf, ...
```

失敗したとき（ファイルがない、オプションが不正など）は、理由を表示して終了コード 1 で終わります。

## 余白の書き方

CSS の `margin` と同じ順番で、1〜4個の値を空白で区切って書きます。単位は `mm` `cm` `in` `px` が使えます。単位を省くと `mm` になります。

| 書き方 | 上 | 右 | 下 | 左 |
| --- | --- | --- | --- | --- |
| `16mm` | 16mm | 16mm | 16mm | 16mm |
| `8mm 16mm` | 8mm | 16mm | 8mm | 16mm |
| `8mm 16mm 12mm` | 8mm | 16mm | 12mm | 16mm |
| `8mm 16mm 12mm 20mm` | 8mm | 16mm | 12mm | 20mm |

空白を含むので、引用符で囲んでください。

```bash
md-to-pdf doc.md --margin "8mm 16mm"
```

ページ番号は下の余白の中に描きます。下の余白を小さくするとページ番号が窮屈になるので、そのときは `--no-page-numbers` を使ってください。

## Front matter

ファイルの先頭に `---` で囲んだ設定を書くと、その文書だけの設定になります。

```markdown
---
title: 要件定義
format: A4
margin: 8mm 16mm
landscape: false
pageBreak: "# ##"
---

# 要件定義
```

| キー | 内容 |
| --- | --- |
| `title` | PDF の文書タイトル（ビューアーのタイトルバーに出るもの）。省略すると最初の `#` 見出し、それもなければファイル名 |
| `format` | `--format` と同じ |
| `margin` | `--margin` と同じ |
| `landscape` | `true` で横向き |
| `pageBreak`（`page-break` も可） | `--page-break` と同じ |

- 設定の優先順位は「既定値 < front matter < コマンドライン」です
- `キー: 値` の1行ずつの形だけを読みます（入れ子の YAML は使えません）
- front matter は PDF には出ません。ファイルの先頭にない `---` は区切り線として扱います

## 図が大きいとき

ページに収まらない Mermaid の図は、ページの幅と高さに収まるまで縮小します。70% より小さくしたときは、次のような注意を出します。

```
注意: 図3 をページ内に収めるため 42% に縮小しました。読みにくい場合は --format A3 または --landscape を試してください。
```

横に長い図（ガントチャートなど）は `--landscape`、全体に大きい図は `--format A3` にすると読みやすくなります。

# 組版と改ページ

[README](../README.md) > 組版と改ページ

md-to-pdf は、ブラウザの印刷機能を使わずに自分でページを割り付けます。目的は「読む人がページをめくったときに、見出しだけ・図の半分だけが取り残されない」ことです。

## 基本の考え方

文書をまず段落・見出し・図・コード・表の行などの「ブロック」に分け、それぞれの高さを測ってから、上から順にページへ詰めていきます。

- 段落は行の単位で折り返します。ページをまたぐときは、収まらない段落ごと次のページへ送ります
- 図、1ページに収まるコードと引用、表の各行は、ページの途中で分割しません
- 1ページに収まらないコードはページごとに分け、収まらない引用は中身を順に並べます
- 長い表は行の間でだけ改ページし、見出し行を次のページの先頭にも繰り返します

## 見出しを取り残さない

見出しは、直後の内容と同じページに置きます。

1. 見出しから次の同じレベル以上の見出しまで（節）が残りのスペースに収まるなら、節をまるごと置きます
2. 収まらないけれど1ページには収まるなら、節をまるごと次のページへ送ります
3. 1ページにも収まらない長い節は、見出しと最初の塊（段落・表の最初の行・図など）だけをくっつけて、残りは流れるように続けます

見出しが続くとき（`##` の直後に `###` など）は、まとめて1つの塊として扱います。

## 見出しの直後の図

見出しのすぐあとに図があるときは、見出しと図が同じページに収まるよう、見出しの高さの分だけ図を小さくします。ただし、それで図の高さがページの60%を下回るときは小さくせず、ページいっぱいまでの大きさにします。

## 改ページ（`--page-break`）

どの見出しの前で必ず改ページするかを選べます。選ばなかった見出しは、上の規則に従ってはみ出るときだけ改ページします。

| 指定 | 必ず改ページ | はみ出るときだけ改ページ |
| --- | --- | --- |
| `"#"`（既定） | `#` | `##` 以降 |
| `"# ##"` | `#` `##` | `###` 以降 |
| `"# ## ###"` | `#` `##` `###` | `####` 以降 |
| `none` | なし | すべての見出し |

```bash
md-to-pdf doc.md --page-break "# ##"
md-to-pdf doc.md --page-break 1,2      # 上と同じ
md-to-pdf doc.md --page-break "h1 h2"  # 上と同じ
md-to-pdf doc.md --page-break none
```

front matter では `pageBreak: "# ##"`、ライブラリでは `pageBreak: '# ##'` か `pageBreak: [1, 2]` です。

- `#` の数でも、数字（`1,2`、`h1 h2`）でも書けます。`#` を含むので引用符で囲んでください。`none` `off` `0` は「必ず改ページする見出しなし」です
- 文書の最初の見出しの前では改ページしません
- 見出しが続くとき（`#` の直後に `##` など）は、`##` も改ページの対象でも、まとめて同じページに置きます。間の区切り線（`---`）は無視します
- 改ページする見出しの直前にある区切り線（`---`）は、改ページと重なるので描きません
- HTML の `<h1>`〜`<h6>` も対象です

`#` を文書のタイトル、`##` を章として使うなら `"# ##"` にすると、章ごとに新しいページから始まります。

## ページの見た目

| 項目 | 値 |
| --- | --- |
| 本文 | Noto Sans JP 10.5pt、行の高さ 1.75 |
| 見出し | `#` 22pt、`##` 16pt、`###` 13pt、それ以降 11.5pt（太字） |
| コード | 等幅 8.5pt、行の高さ 1.5、灰色の背景 |
| 表 | 8.75pt（列が多いときは 8pt、7.5pt） |
| ページ番号 | 右下に `3 / 12` の形（`--no-page-numbers` で消せます） |
| 余白 | `16mm 16mm 18mm 16mm`（上 右 下 左。`--margin` で変更） |

## 行の折り返し

- 日本語は文字の間で、英語は単語の間で折り返します。長い英単語や URL は途中で折り返します
- 行頭に来てはいけない文字（`、` `。` `」` `）` `!` `?` など）と、行末に来てはいけない文字（`「` `（` など）は、前後の文字と一緒に送ります
- 改行だけでつないだ行は、日本語どうしなら詰めて、英語ならスペースを入れてつなぎます
